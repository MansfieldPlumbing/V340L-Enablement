# Repository disposition audit
Date: 2026-10-01.

## Before the pivot
The root mixed driver preparation, DirectML verification, native ggml interception, shim generation, downloaded runtimes, scratch instrumentation, and Vulkan transport proofs. Several tracked `VulkanProofs/` files had already been removed from that obsolete location; the live immutable proofs were under `GGML/Vulkan/Proofs/`. The README still described a future inference backend and omitted later controlled model results.

## Retained supported surface
- `Prepare-AmdPro22Q4V340L.ps1`: download, provenance checks, extraction and narrowly scoped INF preparation.
- `Probe-DirectMLV340.ps1`: D3D12/DirectML adapter/operator probe.
- `Test-DirectMLGemm.ps1`: deterministic FP16 operator execution/readback validation.
- `src/New-WindowsFunctionPointerBinder.ps1`: shared PowerShell interop helper.
- `Verify.ps1`: device/operator checks only, with JSON receipts.
- Driver documentation and benchmark/postmortem evidence.

Standalone diagnostic GEMM readback is a terminal correctness check; it is not an allowed bridge between inference devices.

## Archived
All root ggml interception tests and baton emitters were moved to `ggml-vulkan/`. Vulkan scripts, shaders, historical receipts and integration source/logs were collected there. The failed project's performance claims were replaced with qualified measurements. Original proofs were hashed before reorganization and retained at their original paths.

## Publication exclusions
Build output, generated DLLs, downloaded runtime/model/driver payloads, local caches and scratch work are ignored. Evidence publication uses source and text/JSON receipts, with an integrity inventory. Paths and adapter identities in historical diagnostics are provenance; no credentials should be published.

The repository name becomes V340L-Enablement. The existing local checkout path is deliberately retained because the user's immutable-proof directive names that exact path. Repository naming and local directory naming are independent.

## DirectAI
DirectAI is a separate project. Its publication review includes source inventory, dependency audit, ignored artifacts/history checks, a complete build and CLI/PowerShell smoke checks. Missing modular project definitions were repaired. This is a bounded release hygiene review, not a full security audit or a qualification of every inference plugin/model.
